# BLOOD DONOR FINDER – HOW TO RUN (XAMPP)

### 1. Installation
1. Install XAMPP and start Apache and MySQL.
2. Copy the `blood-donor-finder` folder into `C:\xampp\htdocs\`.
3. Open phpMyAdmin: `http://localhost/phpmyadmin`
4. Import the `database.sql` file.
5. Open the application: `http://localhost/blood-donor-finder/`

### 2. Admin Login
Admin Login Page:

`http://localhost/blood-donor-finder/admin/login.php`

Username: Use the configured administrator username.

Password: Use the configured administrator password.

**Note:** Administrator credentials should be kept private and must not be published in this repository.

### 3. Project Pages

- `index.php` – Home Page
- `register.php` – User Registration
- `login.php` – User Login
- `donor_register.php` – Donor Registration
- `search.php` – Search Blood Donors
- `request.php` – Blood Request and Emergency Request
- `requests.php` – View Open Blood Requests
- `profile.php` – Donor Profile Management
- `admin/dashboard.php` – Admin Dashboard
- `contact.php` – Contact Page

### 4. Technologies Used
- HTML
- CSS
- JavaScript
- PHP

- XAMPP

### 5. Database
Database Name: `blood_donor_finder`

Import `database.sql` using phpMyAdmin before running the application.
