BLOOD DONOR FINDER – HOW TO RUN (XAMPP)
1. Install XAMPP and start Apache and MySQL.
2. Copy the "blood-donor-finder" folder into C:\xampp\htdocs\
3. Open http://localhost/phpmyadmin -> Import -> choose database.sql -> Go.
4. Open http://localhost/blood-donor-finder/
5. Admin: http://localhost/blood-donor-finder/admin/login.php
   Username: admin   Password: admin123  (created automatically on first visit)

PAGES: index (Home), register/login (User), donor_register (Donor Registration),
search (Search Donors), request (Blood Request + Emergency), requests (Open Requests),
profile (Donor Profile Management), admin/dashboard (Admin), contact (Contact Page).
